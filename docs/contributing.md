# 协作与交付

1. 克隆仓库，按任务创建分支，例如 data/preparation、model/custom-cnn、model/resnet18、evaluation/metrics。
2. 在对应目录加入实际代码和配置，并更新运行说明。不要仅提交 notebook 中无法重现的输出。
3. 正式训练前由全组确认 splits/ 的划分与标签顺序。变更须版本化并通知所有成员。
4. 模型成员按预测接口导出 CSV，附配置、实际轮数、日志及 checkpoint 获取位置。大权重放外部存储，仅记录访问方式。
5. 提交前运行评估检查，检查暂存文件没有数据包、密钥或本机绝对路径。
6. 发起 Pull Request，由相关负责人核对后合并。Member D 汇总指标、报告和 PPT，全员分别确认自己的事实。

README 中明确区分计划、代码已实现、训练中、完成验证。报告数字必须能够回溯到实际预测与 run_id。
